# **App Name**: Scootix Hub

## Core Features:

- Service Booking: Allow users to book maintenance and repair services online with a date and time picker.
- Online Store: Enable users to purchase scooter parts, batteries, and accessories through an e-commerce platform.
- DIY Kit Recommendations: AI Tool suggests relevant DIY kits based on scooter model and user-reported issues to help with basic maintenance.
- Subscription Plans: Offer subscription-based maintenance plans with different tiers and benefits.
- Payment Gateway: Integrate secure payment processing via Stripe or Mercado Pago for purchases and service bookings.
- Order Management: Manage the orders for the scooter's parts, batteries, or accessories, keeping track of status changes and generating reports for admin.

## Style Guidelines:

- Primary color: Electric Blue (#007BFF) to convey technology and trust.
- Background color: Very light blue (#E5F3FF) creates a clean and calming backdrop.
- Accent color: Lime Green (#32CD32) highlights the app's committment to sustainability and eco-friendliness.
- Body and headline font: 'Inter', a sans-serif font providing a modern and neutral aesthetic, suitable for both headlines and body text.
- Use modern, minimalist icons to represent services, categories, and features.
- Employ a clean and structured layout with clear hierarchy for easy navigation.
- Subtle animations and transitions to enhance user experience.
